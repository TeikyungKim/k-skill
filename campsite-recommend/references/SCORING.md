# 추천 점수 산식

`run_campsite_recommend.py`가 쓰는 종합점수는 **베이지안 보정 평점 70% + 로그 정규화 리뷰 규모 30%**다.

```
보정평점 = (평가수 × 평점 + 10 × 4.1603) / (평가수 + 10)
평점항  = 보정평점 / 5 × 100
리뷰항  = ln(1 + 평가수 + 리뷰수) / ln(1 + 979) × 100
종합점수 = 0.7 × 평점항 + 0.3 × 리뷰항
```

- **평점 / 평가수**: 카카오맵 별점 평균과 별점 평가 건수 (`kakaomap_review.score_set.average_score` / `.review_count`)
- **리뷰수**: 카카오맵 블로그 리뷰 건수 (`blog_review.review_count`)

## 상수의 유래 (동결됨)

| 상수 | 값 | 유래 |
| --- | --- | --- |
| 사전 평균 | 4.1603 | 2026-08 숲나들e 비교군 107곳의 평점 평균 |
| 사전 표본 | 10 | 같은 판에서 정한 베이지안 prior 가중치 |
| 리뷰 정규화 기준 | 979 | 같은 판 모집단 최대치(장태산자연휴양림 평가수+리뷰수) |

이 상수들은 **판(스냅샷) 간 점수를 비교할 수 있도록 의도적으로 동결**돼 있다.
리뷰 수가 979를 넘으면 리뷰항이 100을 넘을 수 있는데, 이는 버그가 아니라
동결의 대가다. 상수를 갱신하면 과거에 만든 순위표와 점수를 비교할 수 없게
되므로, 갱신할 때는 산식 버전을 명시하고 과거 표와 비교하지 않는다.

## 점수가 반영하지 않는 것

사이트 크기, 차량 진입, 전기, 샤워장, 반려견, 계곡·물놀이, 동계 운영 여부는
점수에 들어가지 않는다. 최종 선택 전 공식 시설 안내와 최근 후기를 확인한다.

## 검산 예시

장태산자연휴양림, 평점 4.5 · 평가수 235 · 리뷰수 744 (2026-08-29 스냅샷):

```
보정평점 = (235×4.5 + 41.603) / 245 = 4.4861
평점항  = 89.72
리뷰항  = ln(980)/ln(980) × 100 = 100.0
종합점수 = 0.7×89.72 + 0.3×100 = 92.81
```
